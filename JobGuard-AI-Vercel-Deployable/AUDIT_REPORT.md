# JobGuard AI — Audit Report

## Audit scope

Inspected the FastAPI backend, React/TypeScript frontend, SQLite authentication database, Supabase schema, CI workflow, Docker configuration, tests, and production bundle.

No official Hack2Skill rubric or submission-specific evaluation document was present in the repository. The score below therefore uses the provisional 100-point framework from the submitted prompt.

## Pre-implementation findings

1. Authentication UI was implemented but not integrated into the main application.
2. The application replaced account state with a demo evaluator identity.
3. Demo/real report classification could inherit stale state.
4. Password recovery and email verification were not configured honestly.
5. Ordinary registration responses previously exposed a verification token.
6. Report saving did not reject identifier collisions across accounts.
7. There was no protected GET endpoint for a single owned report.
8. Password changes did not revoke other sessions.
9. Document upload validation used extension and size but not basic content signatures.
10. Production CORS could remain on development defaults unless explicitly configured.
11. Frontend production build was connected to CI but CI did not run it directly.
12. A single standalone `app.js`/`styles.css` compatibility fallback was not generated by Vite.

## Improvements completed

- Centralized session state and restored `/api/auth/me` on startup.
- Integrated guest, login, register, profile, password, and account-deletion workflows.
- Added hashed, expiring, one-time recovery and verification tokens.
- Added honest SMTP availability reporting and environment-only delivery configuration.
- Added report ownership collision protection and protected report retrieval.
- Added account password-change session revocation.
- Added report size limits and document content-signature validation.
- Added production fail-close CORS behavior when no trusted origin is configured.
- Updated CI for full frontend installation, build, TypeScript validation, and tests.
- Added final compatibility asset generation for the FastAPI static deployment.
- Replaced Vite 5/esbuild 0.21 with Vite 8.3.8/plugin-react 6.3.0; final npm audit reports zero vulnerabilities.

## Project duplicate reconciliation

The repository contained an older nested copy at `jobguard-ai/jobguard-ai/`. A file comparison found no nested-only source file and found seven differing source files. The differing nested files were older copies of canonical files; no unique implementation was lost. The nested copy was removed.
